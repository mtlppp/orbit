# 星軌跳躍

一款點一下就發射的太空軌道跳躍遊戲：抓準時機，從一顆星球跳到下一顆，越跳越遠。

## 檔案
- `index.html`：遊戲本體（程式、樣式、繪圖、音效全部內嵌，無外部資源、無字型下載）
- `sw.js`：Service Worker，首次開啟時預先快取全部檔案
- `manifest.webmanifest`、`icon.svg`、`icon-192.png`、`icon-512.png`：PWA 安裝資料

## 啟動
- 以任何靜態網頁伺服器提供此資料夾（須為 HTTPS 或 localhost 才能離線快取），例如：`python3 -m http.server 8080`
- 手機瀏覽器開啟網址即可遊玩。

## 首次使用與離線
1. 連網狀態下開啟網址一次，等主畫面左下顯示「已可離線遊玩」。
2. （建議）加到主畫面：iPhone Safari →分享→加入主畫面；Android Chrome →選單→安裝應用程式／加到主畫面。
3. 之後即使斷網，從主畫面圖示或同一網址重新開啟都能遊玩。

## 操作與目標
- 點擊畫面任何位置：飛船沿虛線（切線）方向發射。
- 飛進下一顆星球的虛線引力圈即降落；瞄準星球正中可觸發「正中」連擊加分。
- 收集青色星塵 +1 分，並為當前星球補回 1 秒停留時間。
- 每顆星球停留有時限（白色圓弧），時間到會自動發射。
- 飛出左右邊界、墜落、迷失虛空或撞上隕石即結束。
- 區域依跳躍數推進：近地軌道 → 琥珀星雲（移動星球）→ 碎石帶（隕石）→ 深空邊境 → 黑洞視界。
- 右上暫停鍵：繼續／重新開始／回主畫面／音效開關。
